# Mathematical Formulae, Statistical Tables & Optical Character Recognition (Math Formula OCR) Reference Guide

**Author:** Islam Ayoub — *Utilvo Research & Document Engineering Group*  
**Technical Report:** `UTR-2026-04` (October 2026, 13 Pages)  
**Reserved DataCite DOI:** `10.17632/nx3pcfmjkx.1`

## Abstract

This open-access reference guide and benchmark compilation provides a standardized 13-page datasheet of core mathematical formulae and statistical critical value tables paired with an architectural evaluation of Optical Mathematical Character Recognition (**Math Formula OCR**). It covers algebraic series, hyperbolic and trigonometric identities, differential and integral calculus, numerical analysis (Simpson's Rule, Newton-Raphson iteration), discrete and continuous probability distributions, standard normal $Z$-tables, Student's $t$-distribution, $\chi^2$ critical values, and two-dimensional syntactic layout parsing for converting raster and PDF mathematical expressions into canonical **LaTeX (`AMS-LaTeX`)** and **W3C MathML 3.0**.
